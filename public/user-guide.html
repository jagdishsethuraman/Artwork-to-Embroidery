EmbroideryTrace Studio User Manual

Official visual documentation and operational reference for converting digital artwork and typography into commercial embroidery stitch files.
Figure 1: EmbroideryTrace Studio Interface (Geist Atelier Edition with Vercel Vignette Void) v2.0 Atelier

EmbroideryTrace Studio is an in-browser CAD workstation built specifically for commercial embroidery machine digitizing. It runs completely offline on your local machine with 0 external network transmission, guaranteeing absolute design privacy.

2. Interface Anatomy: What is Where

The workspace is split into three unified sections designed for seamless left-to-right digitizing:

Workspace Section Core Controls Primary Function
Left Sidebar Presets (Daisy, Mono, Crest), Layer Stack, Eye Visibility Toggle, 6-Dot Drag Handles, Telemetry Card Sequence thread colors, control sewing order (underlay foundations before top outlines), and inspect millimeter dimensions.
Center Viewport HUD (Inspect Pan, Knife Split, Hoops, Zoom, Metric Grid, Vignette), Reticle, DAW Timeline Deck Real-time 60fps canvas stage. Inspect needle drops, simulate machine sewing, check hoop clearance, and analyze stitch commands.
Right Sidebar Weave Selector, Stitch Density, Step Length, Stitch Angle, Pull Comp, Underlay, Generate Button Calibrate computational textile parameters with editable numeric fields and 3px hairline sliders.

3. Deep Dive: The Import Artwork Window

Clicking [Import Artwork] in the top header opens the 3-pane raster tracing and color quantization engine.

Figure 2: 3-Pane Live Pipeline (Original Bitmap → CIELAB Quantization → Marching Squares Vector Outlines) K-Means++ & Marching Squares

The pipeline operates across 3 synchronized columns:

  1. Original Bitmap: Shows the raw RGB raster file with dimensions in pixels.
  2. Thread Palette: Shows the isolated color clusters matched to physical Madeira Polyneon 40wt thread spools.
  3. Vector Outlines: Shows the closed vector contours extracted via marching squares with negative hole punch-outs.
Figure 3: Import Artwork Parameters (Target Width, Detail Smoothing, Grain Flow, Auto Weave) Physical Textile Parameters

Understanding the Import Sliders

Setting Default What It Controls
Target Hoop Width 75 mm The physical scale in millimeters. Images are pixel-based; embroidery machines require millimeters. This defines the final real-world width and scales height proportionally.
Thread Colors (K) 3 colors Number of distinct physical embroidery thread spools. Clusters millions of raster pixels into $K$ dominant masks in CIELAB space, eliminating noisy gradient transitions.
Detail Smoothing (RDP) 0.8 mm Ramer-Douglas-Peucker tolerance. Converts jagged pixel staircase edges into smooth machine vector splines, eliminating needle-damaging micro-stitches ($<0.35\text{mm}$).
Grain Flow Angle 45° Scanline grain orientation. Embroidery threads reflect light directionally; setting a unified 45° angle ensures consistent luster and prevents fabric seam clashing.
Default Stitch Weave Twill Weave The weave structure applied to filled regions. Twill uses a 4-step staggered offset for maximum richness.
Filtering Checkboxes All Checked Automatically ignores pure white JPEG canvas backgrounds (>245), strips transparent PNG alpha, and suppresses outer die-cut white sticker margins.
The 6mm Rule: Narrow elements between 1.0mm and 6.0mm automatically receive high-sheen dual-rail Satin Stitches. Elements wider than 6.0mm automatically receive Tatami / Twill Fills with 3.5mm needle drops to prevent long, snag-prone thread floats.

4. Typography & Satin Lettering Engine

Clicking [Add Lettering] opens the in-canvas typography modal for generating collegiate block, serif, and scripted lettering.

Figure 4: Typography Modal with Font Selection, Baseline Height, and Polar Arc Warping Arc Warping Engine

Key Lettering Features:

  • Arc Curve Slider (-60° to +60°): Bends text along a smooth mathematical polar arch before stitch generation, ensuring needle drops remain perpendicular to the curve.
  • Automatic Hole Punching: Automatically extracts inner cutout loops in letters like A, B, O, D, and P, preventing stitches from traversing through negative space.
  • Minimum Height Guideline: Standard 40wt thread is 0.4mm thick. For clean, legible satin lettering, keep letter height at $\ge 12\text{mm}$.

5. Weave Types & Physical Parameters

Fine-tune machine stitch compilation in the right sidebar:

Parameter Recommended Description & Adjustment Guidelines
Stitch Density (Row Pitch) 0.40 mm Distance between parallel thread scanlines. Decrease to 0.35mm for coarse fabrics (piqué polo, knit sweaters) to prevent fabric peek-through. Increase to 0.45mm for lightweight silk or sheer fabrics.
Stitch Step Length 3.5 mm Distance between consecutive needle drops along a scanline. Decrease to 2.8mm for intricate curves; increase to 4.5mm for fast flat fills.
Stitch Angle 0° – 360° Rotates the grain flow of the active thread layer.
Pull Compensation +0.30 mm Outward boundary expansion. Thread tension shrinks fabric along the stitch line. Pull comp widens boundaries to guarantee perfect registration against neighboring outlines. Use +0.5mm on stretchy t-shirt knits.
Generate Underlay Checked Lays a preliminary foundation lattice that tacks fabric to backing stabilizer and flattens fabric pile before top stitching.

6. CAD Reticle & DAW Simulation Deck

Simulate how your embroidery machine will sew every single stitch before sending files to production:

  • Color-Blocked Timeline Track: Each colored bar is proportional to that thread layer's stitch count. Click any bar to jump playback directly to that layer.
  • CAD Virtual Needle Reticle: High-visibility brass reticle tracking the needle drop, displaying active command and distance (e.g. STITCH 2.4mm, JUMP 8.2mm, TRIM, COLOR STOP).
  • Hoop Envelope Alerts: If your design exceeds the active commercial hoop's 5mm safety margin, a red ⚠ +X mm alert pill appears instantly.

9. Troubleshooting & FAQ

Why did my stitches pull in and leave gaps around outlines?

This is standard fabric pull distortion. Thread tension physically pulls fabric inward. In the right sidebar, increase Pull Compensation to +0.4mm or +0.5mm, and verify that Generate Underlay is checked.

Why is the machine stopping multiple times for the same color?

In standard digitizing, fragmented islands cause extra stops. EmbroideryTrace Studio automatically groups all disconnected patches of the same color into a single ColorLayer channel, eliminating redundant stops.

What is the difference between Twill and Tatami?

Both are dense structural fills. Tatami uses a standard 1/3-offset brick pattern. Twill uses a 1/4-staggered offset that produces a pronounced diagonal texture mimicking woven denim and military twills.
